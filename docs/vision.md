Femiciencia Studio nació para que el conocimiento pueda circular con libertad.

Durante años, el equipo de Femiciencia dependió de herramientas externas para publicar sus investigaciones y mantener el vínculo con su comunidad. Este proyecto busca devolver esa autonomía, construyendo una plataforma editorial propia, abierta y pensada desde las necesidades reales de quienes escriben, investigan y comunican ciencia con perspectiva de género.

Cada decisión técnica de este proyecto debe responder a una única pregunta:

¿Hace más fácil que el conocimiento llegue a más personas?
